RELATORIOS.PY - SISTEMA DE GERACAO DE RELATORIOS
==================================================

1. DEPENDÊNCIAS NECESSÁRIAS
---------------------------

Versão necessária: 3.11

Para utilizar todas as funcionalidades (PDF e gráficos), instale as dependências num ambiente virtual.

--- OPÇÃO A: Usando 'uv' (Caso tenha o 'uv' instalado) ---

1. Criar e instalar dependências:
   uv venv
   .\.venv\Scripts\activate   # (no Linux/macOS use: source .venv/bin/activate)
   uv pip install reportlab matplotlib

**Lembrar de selecionar o ambiente virutal uv --> caminho criado de acordo com a maquina.


--- OPÇÃO B: Usando o caminho do Python instalado e ambiente virtual (.venv) ---

Caso não instale com a uv descrita e não encontrando o python, selecionar após criação do .venv


python -m pip install reportlab matplotlib

ou

py -m pip install reportlab matplotlib 



--- OPÇÃO C: Usando Python Padrão (Recomendado) ---

1. Criar o ambiente virtual:
   python -m venv .venv

2. Ativar o ambiente virtual:
   - Windows (PowerShell): .\.venv\Scripts\Activate.ps1
   - Windows (CMD):        .\.venv\Scripts\activate.bat
   - Linux / macOS:        source .venv/bin/activate

3. Instalar as bibliotecas:
   pip install reportlab matplotlib
 

IMPORTANTE: 
- As funcionalidades de CONSULTA, CSV e RELATORIO DE UTILIZADORES 
  funcionam SEM a instalacao das bibliotecas.
- As funcionalidades de PDF e GRAFICOS (opcao 4) so funcionam 
  COM a instalacao das bibliotecas.

2. ESTRUTURA DE PASTAS
----------------------
O sistema espera a seguinte estrutura:

projeto/
├── relatorios.py          # Script principal
├── logs/                  # Pasta com arquivos de log (.log ou .txt)
│   ├── sistema.log
│   └── analytics.log
└── relatorios_pdf/        # Pasta onde os relatorios serao salvos (criada automaticamente)

3. CONFIGURACAO DE CAMINHOS
---------------------------
Os caminhos sao definidos no inicio do arquivo relatorios.py:

DIRETORIO_BASE = Path(__file__).resolve().parent
PASTA_LOGS = DIRETORIO_BASE / "logs"
PASTA_RELATORIOS = DIRETORIO_BASE / "relatorios_pdf"

IMPORTANTE: Em integracao, altere o caminho PASTA_LOGS conforme necessario.

4. FORMATO DOS ARQUIVOS DE LOG SUPORTADOS
------------------------------------------
O sistema reconhece dois formatos de log:

FORMATO 1 (ANALYTICS):
2024-01-20 14:30:25 [INFO] MODULO AUTENTICACAO: Login do utilizador 'admin' com sucesso

FORMATO 2 (ALTERNATIVO):
2024-01-20 14:30:25 [INFO] MODULO AUTENTICACAO: Login do utilizador 'admin' com sucesso

Extensoes suportadas: .log e .txt

5. FUNCIONALIDADES DO SISTEMA
-----------------------------
O sistema oferece as seguintes opcoes no menu principal:

1. Consultar Sistema
   - Exibe estatisticas gerais
   - Lista modulos encontrados
   - Mostra utilizadores identificados
   - Exibe eventos por tipo
   - NAO requer bibliotecas externas

2. Detalhar Eventos por Modulo
   - Analise detalhada por modulo
   - Distribuicao por severidade
   - Lista de utilizadores por modulo
   - Ultimos eventos de cada modulo
   - NAO requer bibliotecas externas

3. Gerar Relatorio Analitico (Texto)
   - Relatorio completo em formato texto
   - Exibe no console
   - Inclui todas as estatisticas
   - NAO requer bibliotecas externas

4. Gerar Relatorio PDF com Graficos
   - Relatorio em formato PDF
   - Inclui graficos gerados com matplotlib
   - Graficos: modulos, severidades, tipos de evento
   - REQUER reportlab e matplotlib instalados
   - Abre automaticamente apos geracao

5. Exportar CSV
   - Exporta dados para CSV com 6 colunas:
     ID, Data/Hora, Status, Modulo, Observacao, Utilizador
   - Permite selecionar um modulo especifico ou todos
   - PERMITE ESCOLHER O SEPARADOR:
     - Opcao 1: Ponto e virgula (;) - Recomendado para Excel PT-BR/PT-PT
     - Opcao 2: Virgula (,) - Recomendado para Excel EN-US/Internacional
     - Opcao 3: Tab (\t) - Para sistemas que usam tabulacao
     - Opcao 4: Ambos (gera dois arquivos: um com ; e outro com ,)
     - Enter: Usa ponto e virgula como padrao
   - NAO requer bibliotecas externas
   - Abre automaticamente apos geracao

6. Reler Logs da Pasta
   - Recarrega todos os arquivos de log
   - Limpa os dados anteriores
   - Atualiza as estatisticas
   - NAO requer bibliotecas externas

7. Relatorio de Utilizadores
   - Classifica utilizadores em:
     - ATIVOS: Aparecem nos logs
     - DESATIVADOS: Identificados por eventos de desativacao
     - EXCLUIDOS: Identificados por eventos de exclusao
   - Permite exportar para PDF (REQUER reportlab)
   - NAO requer bibliotecas para consulta

8. Debug
   - Exibe os primeiros 30 eventos carregados
   - Lista utilizadores desativados e excluidos
   - Mostra total de eventos e utilizadores
   - NAO requer bibliotecas externas

6. DETALHES DA EXPORTACAO CSV
-----------------------------
O CSV gerado contem as seguintes colunas:

| Coluna | Descricao |
|--------|-----------|
| ID | Numero sequencial do evento |
| Data/Hora | Data e hora do evento (YYYY-MM-DD HH:MM:SS) |
| Status | CRITICO, ATENCAO ou INFO (baseado na severidade) |
| Modulo | Modulo de origem do evento |
| Observacao | Descricao completa do evento |
| Utilizador | Nome do utilizador envolvido (ou "Desconhecido") |

Exemplo de linha CSV (com ponto e virgula):
1;2024-01-20 14:30:25;INFO;AUTENTICACAO;Login do utilizador 'admin' com sucesso;admin

7. COMPATIBILIDADE
------------------
O sistema e totalmente portavel e funciona em:

- Windows 7, 8, 10, 11
- macOS (todas as versoes)
- Linux (Ubuntu, Debian, Fedora, etc.)

Requerimentos:
- Python 3.6+
- Bibliotecas: reportlab e matplotlib (APENAS para PDF e graficos)

8. SOLUCAO DE PROBLEMAS
-----------------------
ERRO: "ModuleNotFoundError: No module named 'reportlab'"
SOLUCAO: pip install reportlab

ERRO: "ModuleNotFoundError: No module named 'matplotlib'"
SOLUCAO: pip install matplotlib

ERRO: "pip nao e reconhecido como um comando"
SOLUCAO: Use python -m pip install reportlab matplotlib

ERRO: "Nenhum arquivo .log ou .txt encontrado"
SOLUCAO: Verifique se a pasta logs existe e contem arquivos

ERRO: "Pasta de logs nao encontrada"
SOLUCAO: Verifique a configuracao de PASTA_LOGS no codigo

ERRO: "Permission denied" ao criar pastas
SOLUCAO: Execute o programa com permissoes de administrador

9. EXEMPLO DE EXECUCAO
----------------------
1. Coloque os arquivos de log na pasta logs/
2. Execute: python relatorios.py
3. O sistema carregara os logs automaticamente
4. Escolha uma opcao do menu

Exemplo de execucao para exportar CSV:
- Opcao 5 (Exportar CSV)
- Escolha o modulo (ou 'n' para todos)
- Escolha o separador (1=;, 2=,, 3=tab, 4=ambos, Enter=padrao)
- O CSV sera gerado e aberto automaticamente

10. NOTAS IMPORTANTES
---------------------
- A pasta relatorios_pdf e criada automaticamente na primeira execucao
- Os arquivos gerados tem timestamp no nome: csv_modulo_20260121_143022.csv
- O CSV e salvo com encoding UTF-8 com BOM para compatibilidade com Excel
- O sistema e otimizado para performance com cache LRU
- Logs sao salvos em logs/relatorios.log para debug
- Para utilizar PDF e graficos (opcao 4), instale reportlab e matplotlib
- Sem as bibliotecas, as demais funcionalidades continuam disponiveis

11. PERSONALIZACAO
------------------
Para alterar o separador padrao do CSV, modifique a linha no codigo:
writer = csv.writer(f, delimiter=";", quoting=csv.QUOTE_ALL)

Para alterar a pasta de logs, modifique:
PASTA_LOGS = DIRETORIO_BASE / "logs"

12. SUPORTE
-----------
Para duvidas ou problemas, verifique o arquivo de log:
logs/relatorios.log
